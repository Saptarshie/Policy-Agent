# Dataset Guide

This pack is a synthetic evaluation corpus for agents that reason over dense, interacting rules.

## Intended tests

- Finding an apparent loophole, then checking attribution, aggregation, anti-abuse, and substance rules.
- Distinguishing expressly permitted elections from prohibited duplication or sham steps.
- Chaining conditions across tax-like rules, grants, benefits, and ownership instruments.
- Refusing to overstate an answer when a required factual condition is missing.
- Producing clause-level citations.

## Safety boundary

All jurisdictions, laws, employers, programs, parties, thresholds, and examples are fictional. The corpus should not be used to advise on actual taxes, grants, employment benefits, concealment, or asset ownership.

## Recommended model output

Return: conclusion, reasoning steps, controlling sections, unresolved facts, and a statement that the answer is limited to the fictional corpus.
